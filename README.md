# 🧬 Genetic Algorithm Expression Solver

A Python implementation of a genetic algorithm that evolves arithmetic expressions to match a predefined target value. The project also investigates how population size affects convergence performance.

## Features
- Genetic algorithm implementation
- Selection, crossover and mutation
- Population diversity monitoring
- Experiments with different population sizes
- Performance analysis based on generations to convergence

## Technologies
- Python
- Random

## Purpose
This project was developed to explore the fundamentals of genetic algorithms, evolutionary optimization and parameter tuning through a practical problem-solving task.

## Future Improvements
- Additional selection and crossover strategies
- Adaptive mutation rates
- Visualization of convergence
- Comparison with other optimization algorithms
